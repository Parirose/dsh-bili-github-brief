# v0.1.0 — 初始公开版

B站 + GitHub AIGC 日报生成器，面向 DeepSeek Harness (DSH) 与 NapCat。

每天按关键词搜索 B站视频和 GitHub 仓库，读取字幕、简介、README、releases 和 ComfyUI workflow JSON，生成一份本地 Markdown 日报，再通过 NapCat 推送到 QQ 群或私聊。

## 包含功能

- B站关键词搜索、视频信息、字幕、评论读取
- GitHub 仓库搜索、README、tree、file、releases、workflow 读取
- ComfyUI workflow JSON 静态解析：节点类型、模型文件、LoRA、自定义节点候选
- 新模型雷达：candidate / watch / confirmed
- 本地完整 Markdown 报告
- QQ 版按长度动态分段，每条 B站 / GitHub 内容带纯 URL
- NapCat `brief_ready` 多群、多私聊、多段投递
- 每日定时开关，默认 09:00，默认关闭
- B站保持只读：不自动评论、不发私信、不打开自动评论

## 安装 DSH 插件

```bash
dsh plugin --profile web add github:Parirose/dsh-bili-github-brief
```

安装后重启 DSH。

> 本项目内部插件 id 仍为 `bili-scroll`，方便从现有配置迁移。不要和上游 `dsh-bili-scroll` 同时安装。

## 安装 NapCat 插件

下载本 Release 的：

```text
napcat-plugin-dsh-bili-forward-v1.0.0.zip
```

解压到：

```text
<NapCat>/plugins/napcat-plugin-dsh-bili-forward/
```

然后在：

```text
<NapCat>/config/plugins/napcat-plugin-dsh-bili-forward/config.json
```

填写群号、私聊 QQ、token，并确认：

```json
{
  "forwardBriefs": true
}
```

通常只需要重启 NapCat，不需要重启 QQ。

## 配置

- B站：在 DSH 设置页点「装主依赖」→「扫码登录」
- GitHub：填写自己的 fine-grained token，建议只给 Public repositories 只读权限
- QQ：填写 NapCat 转发地址和 token，先点「现在跑一轮」测试
- 确认本地报告和 QQ 分段都正常后，再打开每日定时

## 安全边界

- 仓库不包含 Token、Cookie、QQ 群号、真实报告
- 不包含 NapCat 本体
- 不自动发 B站评论或私信
- 自动评论并 @ 你默认关闭
- QQ 版不输出 GitHub Token、B站 Cookie、本机绝对路径

## 已知限制

- B站视频没有字幕时会跳过，除非启用本地转写
- GitHub API 可能限流，报告会记录数据缺口
- ComfyUI workflow 只做静态 JSON 解析，不执行工作流
- QQ 分段为动态 3–8 段，每段不超过约 1500 字符
- 不同 NapCat 版本的插件目录和重启要求可能略有差异
