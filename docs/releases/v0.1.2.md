# v0.1.2 — 客户端注册修复 / NapCat 白名单 / OneBot 直传

这是 `v0.1.1` 之后的修复版，重点解决桌面版 client 重复注册导致的 profile 回滚，并增加 NapCat 白名单说明和 OneBot v11 直传后端。

## Fixed

- `client.js` 注册 id 从旧包名 `dsh-bili-scroll` 改为真实包名 `dsh-bili-github-brief`
  - 原问题：桌面版报 `duplicate factory registration for "dsh-bili-scroll"`
  - 后果：`web boot` 失败 → 应用自动回滚 profile，用户的插件注册和设置被清空
  - `id: bili-scroll` 的 DSH 命名空间保持不变，settings 仍能绑定
- 更新检查与一键升级继续指向本项目自身

## Added

- OneBot v11 直传后端：`qqBackend: "onebot"`
  - 复用现有 `splitBriefParts()`、`briefHash` 去重和 token 逻辑
  - 支持 `send_group_msg` / `send_private_msg`
  - `qqForwardToken` 非空时作为 `Authorization: Bearer <token>` 发送
- `docs/INSTALL.md` / `napcat-plugin/README.md`：补 NapCat 4.18.4x 官方插件白名单
  - 路线 A：给 `napcat.mjs` 加 `napcat-plugin-dsh-bili-forward`
  - 路线 B：走 OneBot HTTP，不加载 NapCat 插件
- `docs/TROUBLESHOOTING.md`：补两个环境坑
  - DSH 文件带 Low 完整性标签导致 QQ.exe 崩溃
  - NapCatQQ Desktop 安装 QQ 报 `os error 5`
- `scripts/verify-host.mjs`：增加 `client.js` 注册 id 检查

## 安装 / 升级

### 标准 web profile

```bash
dsh plugin --profile web add github:Parirose/dsh-bili-github-brief
```

装完重启 DSH。

### DSH 桌面版（Electron）

```powershell
$env:ELECTRON_RUN_AS_NODE = '1'
& 'C:\DSH NEXT\DSH NEXT.exe' 'C:\DSH NEXT\resources\app.asar\lib\plugin-cli.js' `
  desktop add "link:D:\path\to\dsh-bili-github-brief"
```

装完重启 DSH NEXT。

第一次跑一轮前，先初始化 headless profile：

```powershell
& '<app>/DSH NEXT.exe' '<app>/resources/app.asar/lib/plugin-cli.js' headless list
```

### NapCat 插件

下载本 Release 的：

```text
napcat-plugin-dsh-bili-forward-v1.0.0.zip
```

解压到：

```text
<NapCat>/plugins/napcat-plugin-dsh-bili-forward/
```

NapCat 4.18.4x 如果拒载，见 `docs/INSTALL.md` 的白名单说明，或改用 OneBot 直传。

### OneBot v11 直传

```json
{
  "qqBackend": "onebot",
  "qqForwardUrl": "http://127.0.0.1:3000",
  "qqGroupIds": "123456789",
  "qqPrivateIds": "10001",
  "qqForwardToken": "optional"
}
```

DSH 会自动请求：

```text
<qqForwardUrl>/send_group_msg
<qqForwardUrl>/send_private_msg
```
