# v0.1.4 — 模型层镜像 / QQ 目标单一来源 / perDay 硬上限

## 重点

### 1. 设置页能换模型了（P0）

- `llm-pi-ai` / `agent-default-model` 不再由插件写死或写回任何 profile/home。
- 每次跑日报前，插件把 GUI profile 的模型层原文镜像到 headless 临时 overlay。
- 默认先找 `profiles/desktop`，找不到会扫描 `profiles/web` 等其它 profile。
- 老用户的 home patch 迁移：

```powershell
node scripts/migrate-model-layer.mjs
node scripts/verify-host.mjs
```

脚本只搬模型块，保留 home 里其它配置，并留 `.bak-<时间戳>` 备份。

### 2. QQ 目标只填一次（P1）

DSH 设置页新增「QQ 投递渠道」：

```text
off / napcat-plugin / onebot
```

QQ 群号、QQ 号、转发地址、校验口令都在 DSH 插件设置里填。NapCat 插件页的
`groupIds` / `privateIds` 可以留空；插件会把 `targets` 随请求带过去。

QQ 投递开启后，B站私信自动关闭，`bili_send_message` 也不会出现在那一轮的工具列表里。

### 3. perDay 是真上限（P1）

`prompts/brief-prompt.txt` 新增 `{{PER_DAY}}` / `{{ALREADY}}` / `{{LEFT}}`。
`perDay=5` 时，日报里 B站 `### BV` 标题行不超过 5 条；宿主发现超限会写日志并在 QQ 版末尾提示。
QQ 分段超过 8 段时也会明确记日志，不再静默丢尾。

## 数据质量

- `bili_video_info` 改用 `get_tags()` 补标签，实测 `tags` 不再恒为空。
- Windows 依赖增加 `pip-system-certs`；字幕 TLS 失败会返回 `tls_untrusted_ca` 和修复命令。
- uv 下载超时 180 秒，超时会换下一个源；宿主自带 uv 优先复用。

## 升级

```powershell
dsh plugin --profile web add github:Parirose/dsh-bili-github-brief
```

升级后重启 DSH，并在「设置 → 刷B站」点一次「重装主依赖」——旧 venv 不会自动装上新增的 `pip-system-certs`。已有 NapCat 插件不用重装；DSH 会继续兼容旧配置：只填了 `qqForwardUrl` 的老用户会自动按 `napcat-plugin` 处理。
