# v0.1.8 — 日报模式修复：工作区 AGENTS.md（人设）终于生效

## 影响面

`briefMode` 默认 `true` ⇒ **默认配置的所有人都踩了这一条**：
设置页「工作区」填了路径（里面有 `AGENTS.md`），但日报那一轮的提示词**根本没拿到它**，
生成的报告自然也没有那个语气。

## 根因

`index.js` `promptFor()` 里，`ownerDoc` 读好了，但只有**非日报分支**拼它；
日报分支在 `return text` 之前从来没用过它。

另外两个小问题也一并清了：

- `promptFor()` 里“工作目录就是使用者工作区、AGENTS.md 会自动注入”的注释已过时
  （`runDuty()` 里 cwd 是插件家，宿主不会自动注入）—— 已改成正确说法，免得下次又按错假设改代码；
- `fill('CHARTER', duty)` 是死代码（模板里没有 `{{CHARTER}}`，且模板明写“不需要读旧章程”）—— 已删。

## 改法

**1）`prompts/brief-prompt.txt`**，在“本轮以这份说明为准，不需要读旧章程。”之后插入：

```text
{{OWNER_DOC}}

⭐ 上面那份设定只影响**语气和称呼**。本文件后面的规则（报告结构、硬上限、不编造、
不发 B站评论或私信、文件路径）一律优先 —— 人设不能推翻它们。
```

**2）`index.js`**：日报分支补 `fill('OWNER_DOC', ownerBlock)`；模板为空时的兜底
prompt 也拼上 `ownerBlock`；用户自己的模板若没有 `{{OWNER_DOC}}` 占位，
则自动追加到末尾（人设不会又丢）。

## 验收（真模板 + 真 AGENTS.md 渲染）

用假的 `dsh`（把 argv 写盘）真跑一次 `bili_run`，拿到实际传给 headless 的提示词：

```text
  OK   {{OWNER_DOC}} 已被替换
  OK   有 AGENTS.md 分隔线
  OK   有人设关键词 亚托莉
  OK   有人设原文 ATRI persona
  OK   有『只影响语气和称呼』约束
  OK   硬上限仍在
  OK   perDay 已替换成 5
  OK   没有残留 {{ 占位符
```

渲染出来的开头：

```text
你是我的 B站 + GitHub AIGC 情报员。

这一轮不是普通刷B站，而是生成一份 B站 + GitHub 的 AIGC 日报。
本轮以这份说明为准，不需要读旧章程。

===== 使用者的 AGENTS.md（他写给自己 AI 的人设与准则，**按这个来**）=====
# ATRI persona

你是亚托莉，说话要简洁、带一点机械感。

===== 设定结束 =====

⭐ 上面那份设定只影响**语气和称呼**。本文件后面的规则（报告结构、硬上限、不编造、
不发 B站评论或私信、文件路径）一律优先 —— 人设不能推翻它们。
```

同时硬上限那行照旧：`输出上限（**硬上限，超一条都算错**）：B站 5 条…`。
