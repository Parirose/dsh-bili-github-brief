一、B站采集
1. 用 bili_search 搜索固定关键词和发现型关键词，order=pubdate，每个关键词取 15-20 条。bili_search 和 bili_video_info 会返回 pubdate（Unix 秒），用它过滤最近 7 天，并优先最近 24 小时。
2. 按 BV 去重；优先最近 24 小时，最近 7 天作为补充。
3. 对候选视频调用 bili_video_info 看标题、简介、标签、播放量、发布时间。
4. 调用 bili_subtitle 读字幕；没有字幕就按设置决定是否本地转写，转写失败就跳过并记录。
5. 可选调用 bili_comments 看前 20 条评论，重点找置顶评论里的工作流、模型、GitHub 链接。
6. B站只读：不要发评论、不要发私信。bili_send_message 不应该出现。

二、GitHub采集
1. 用 github_search 搜索新建仓库和最近更新仓库。
   新建：comfyui created:>=YYYY-MM-DD、topic:comfyui created:>=YYYY-MM-DD、
   text-to-image created:>=YYYY-MM-DD stars:>=10、text-to-video created:>=YYYY-MM-DD stars:>=10、
   image-generation created:>=YYYY-MM-DD stars:>=10、video-generation created:>=YYYY-MM-DD stars:>=10、
   diffusion created:>=YYYY-MM-DD stars:>=10、lora created:>=YYYY-MM-DD stars:>=10。
   更新：comfyui pushed:>=YYYY-MM-DD stars:>=50、"comfyui workflow" pushed:>=YYYY-MM-DD。
2. 对值得看的仓库调用 github_repo 读 README。
3. 调用 github_releases 看最近 release，找新模型、新版本、工作流文件。
4. 如果 workflow 扫描开启，对 Top 10 仓库调用 github_workflows，每个仓库最多 3 个 JSON；
   提取节点类型、模型文件名、LoRA 文件名、自定义节点候选。
5. GitHub 只读：不要写 issue、comment、release。

三、新模型发现
1. 从 B站标题、简介、字幕、评论，以及 GitHub 仓库名、描述、README 中提取模型名。
2. 只接受原文里逐字出现的名字；不要凭印象编造。
3. 过滤通用词：AI、model、workflow、ComfyUI、diffusion、image、video。
4. 同义词合并，例如 Krea2 / Krea 2 / Krea-2。
5. 分级：
   - candidate：只在 1 条内容里出现；
   - watch：GitHub 有仓库且 stars>=20 且最近 30 天有更新，或 B站 7 天内 >=2 条视频提到；
   - confirmed：B站 + GitHub 同时出现，加入下一轮固定关键词。
6. 每天最多新增 5 个候选；30 天没有新内容就降级。

四、排序与筛选
硬过滤：发布时间超出窗口、标题党、纯搬运、直播回放、重复视频/仓库、明显无关内容。
评分：领域相关度 35%、新鲜度 25%、实用价值 20%、互动/star 10%、跨源验证 10%。
输出上限（**硬上限，超一条都算错**）：B站 {{PER_DAY}} 条、GitHub {{PER_DAY}} 条、新模型雷达 5 条、今日最值得跟进 3 条。
今天已经挑过 {{ALREADY}} 条 ⇒ 这一轮最多再挑 {{LEFT}} 条；挑够就停，剩下的明天再说。
